# prebuilt wheel and fails to *build* from source against modern CPython
# (a C-extension incompatibility with Python's current C API, reproduced
# on 3.12 and 3.14 - not a version-pin issue, an upstream-abandoned-
# package issue), and separately its setup.py forces numpy<2, conflicting
# with every other pin above. services/slope_service.py already treats it
# as optional: a missing/failed richdem import falls back to slope
# strategy v2 (GDAL) and then to rasterio-simple automatically, so skip it
# here rather than let it break the whole geo install for one strategy
# tier. Only install it by hand, into its own isolated environment, if
# you specifically need it.
