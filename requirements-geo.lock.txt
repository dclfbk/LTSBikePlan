# richdem is NOT a dependency at all any more, deliberately: it used to
# back the default "v3" slope strategy (services/slope_strategies.py),
# but that strategy's own core algorithm (deriving a per-cell slope
# raster, then averaging the cells an edge's footprint touched) turned
# out to measurably produce physically impossible readings - a real
# hillside road in Trento read as 55-86% grade against a true ~3-6%,
# because a touched cell near an unrelated nearby cliff dominated the
# mean. Every strategy (except "v1", a separate R-based implementation)
# now computes grade by point-sampling the DEM directly at each edge's
# own vertices (slope_from_dem) - correct, and it needs nothing beyond
# rasterio (already pinned above), so richdem's build issues (no prebuilt
# wheel, fails to build from source against modern CPython, forces
# numpy<2) stopped being relevant rather than being worked around.
